
Cloud computing logical 3 layers
SaaS: Software as a Service.  e.g) S/W, email, A/I, 얼굴 인식, Auth, SMS 등등
PaaS: Platform as a Service.  e.g) O/S, Middleware, DB. Cloud9(개발 환경), Web IDE (VS Code)
	기본 인프라를 신경쓸 필요 없이 개발에만 집중할 수 있다.
	(제공업체가 보안, O/S, Backup, S/W 등 관리)
IaaS: Infrastructure as a Service  e.g) CPU/Mem/Disk/Network → VPC, Storage, Network 임대

VPC (Virtual Private Cloud): AWS cloud 내 구축하는 가상의 네트워크 영역
사용자 정의 가능한 논리적 네트워크 환경. 
VPN (Virtual Private Network): On-prem data center ↔ VPC 간에 

MFA (Multi-Factor Authentication)
Type 1 (Knowledge. STH that you KNOW): password, passphrase, PIN
Type 2 (?. " you HAVE) tokens, Disconnected (OTP), Connected (Card Reader, Wireless Tag), S/W
Type 3 (?. " you ARE): Biometric. 지문, 홍채 스캔, 목소리 인식

SG (Secuirty Group)
내가 허용하지 않은 모든 것은 차단 (기본 차단). SG에서 허용한 것만 트래픽 허용
Cloud에서 뭐가 안 되면 일단 SG부터 확인한다.
↔ Network ACL (기본 허용. 내가 차단한 것만 차단)
