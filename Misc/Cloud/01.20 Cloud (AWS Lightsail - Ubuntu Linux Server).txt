cf. 프로그램 업데이트시 기존 버전을 삭제 후 업데이트하는데,
기존 설정은 남겨두고 프로그램만 삭제하는 기능이 필요. 반면 완전 삭제도 필요

실제 프로그램 설치/삭제 예시:
apt install nginx
apt remove nginx // 재설치할지도 모르니 (업데이트 중일 수도 있으니) 설정 파일 유지
apt purge nginx // 폐기 (완전 삭제)
